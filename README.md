# Wayfire: как запустить

Wayfire — программа на твоём компьютере, а не сайт: сайт не может запускать Minecraft и хранить файлы игры. Команды вводить не нужно.

## Запуск за три шага
1. Один раз поставь Node.js: https://nodejs.org (большая кнопка LTS).
2. Распакуй архив `wayfire-app.zip` **целиком** в любую папку (правая кнопка, «Извлечь всё»). Файл `start.bat` нельзя брать отдельно: он должен лежать рядом с остальными файлами.
3. Открой распакованную папку и дважды щёлкни `start.bat` (Mac и Linux: `start.sh`). В первый раз он скачает Electron, это пара минут. Надписи в чёрном окне английские: так надёжнее на любом Windows.

## Как запускается игра
Wayfire запускает Minecraft сам, вход через Microsoft не нужен. Он скачивает файлы игры с серверов Mojang, проверяет их, собирает команду запуска и стартует игру из папки сборки с твоими модами. Java берётся из официального лаунчера или из системы (если её нет: https://adoptium.net).

1. В Wayfire открой «Настройки» и впиши ник (латинские буквы, цифры и _, от 3 до 16 символов).
2. Создай сборку, поставь моды, на вкладке «Играть» нажми «Играть».

Это офлайн-режим: игра идёт одиночная, по локальной сети и на серверах, где отключена проверка лицензии. Серверы с проверкой лицензии такой аккаунт не пустят, это решает сервер, а не Wayfire. Поддерживаются «Ваниль» и «Fabric».

Старые способы остались в коде и включаются в `config.json`: `"authMode": "official"` (через официальный Minecraft Launcher) или `"authMode": "microsoft"` (нужны CLIENT_ID из Azure и одобрение Mojang).

## Как собрать установщик
**Windows (самый простой путь):** установи Node.js (LTS) с https://nodejs.org, распакуй весь архив и дважды щёлкни `make-installer.bat`. Через несколько минут откроется папка `dist` с файлом `Wayfire-1.0.0-win.exe`. Если появится ошибка про symbolic link, запусти файл от имени администратора.

**macOS и Linux** на Windows собрать нельзя: установщик для macOS собирается только на Mac. Выход без чужих компьютеров: загрузи папку проекта на GitHub (бесплатно), открой вкладку Actions, выбери «Build Wayfire» и нажми «Run workflow» (файл `.github/workflows/build.yml` уже готов). GitHub сам соберёт Windows, macOS и Linux, а готовые файлы появятся внизу страницы запуска в разделе Artifacts.

Готовые файлы положи на сайт в папку `downloads`. Установщик не подписан сертификатом, поэтому Windows может показать окно SmartScreen («Подробнее» → «Выполнить в любом случае»).

## Как дать лаунчер другим людям
1. Дважды щёлкни `make-installer.bat`. Он скачает всё нужное и соберёт установщик `dist\Wayfire Setup.exe`.
2. Отправь этот файл друзьям. Установка как у обычной программы.
3. Windows может показать синее окно «Windows защитила ваш компьютер»: у программы нет платной подписи разработчика. Нажми «Подробнее», потом «Выполнить в любом случае».

Перед сборкой проверь `config.json`: он попадёт в установщик вместе с твоей почтой (она нужна Modrinth). Wayfire игру не продаёт. Купить Minecraft можно на minecraft.net, это нужно для серверов с проверкой лицензии. Лаунчер неофициальный и не связан с Mojang и Microsoft, об этом написано в настройках.

## Игра с другом без сервера
Ничего настраивать не нужно, нужен только чат (Discord, Telegram).
1. **Хозяин:** вкладка «Игра с друзьями», «Я хозяин: создать код». В Minecraft открой мир, нажми Esc и «Открыть для сети». Отправь код другу.
2. **Друг:** «Я друг: вставить код», вставляет код хозяина, нажимает «Создать ответ» и присылает ответный код хозяину.
3. **Хозяин** вставляет ответный код и жмёт «Соединить». У друга в «Сетевой игре» появится мир «Игра Хозяин».

Нужно: у обоих Wayfire, одна версия Minecraft и одинаковые моды. Игра идёт напрямую между вами. Лицензию при заходе в мир проверяет сама игра. Если соединиться не получается, у одного из вас, скорее всего, строгий роутер: тогда помогут программы Tailscale или ZeroTier.

## Необязательно
- **Игра по нику** вместо обмена кодами: нужен «сервер комнат» (`server/signal.js`), его нужно держать включённым на бесплатном хостинге для Node.js. Адрес вписывается в «Настройки», «Лаунчер», «Сервер комнат».
- **Свой вход через Microsoft** вместо официального лаунчера: нужны аккаунт Azure (регистрация просит банковскую карту), CLIENT_ID и одобрение заявки в Mojang (https://aka.ms/AppRegInfo). Тогда впиши CLIENT_ID в `config.json` и поставь `"authMode": "microsoft"`.

## Что проверено, а что нет
Проверено на имитации серверов и на настоящих соединениях внутри компьютера: движок запуска (скачивание, проверка сумм, правила Mojang, нативы, команда запуска, защита от запуска без входа), добавление профиля в официальный лаунчер, обмен кодами, мост до мира Minecraft, каталог и установка модов, сервер комнат, вход через Microsoft.
Не проверялось вживую (в моей среде нет интернета): настоящие серверы Mojang и Microsoft, запуск настоящей игры, настоящие запросы к Modrinth и Fabric, WebRTC через интернет, поиск мира в локальной сети, сборка установщика. Первые запуски могут вскрыть ошибки: пришли скриншот или текст ошибки. CurseForge не подключён: ему нужен отдельный ключ.
